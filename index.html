Indian Stock News Sentiment

Pick up to 3 NSE-listed stocks and a horizon to compare. This pulls recent headlines from Google News, scores each one with FinVADER — a finance-tuned extension of the VADER sentiment model — and compares the net sentiment against how each stock actually moved over that window.

      FinVADER sentiment scoring on public headlines and Yahoo Finance price data — for demonstration only, not financial advice. Correlation from a handful of headlines is illustrative, not statistically meaningful.

      News is fetched via rss2json.com's free tier without an API key (no signup needed). Their documented free-plan limit is 10,000 requests/day per account, but this no-key usage is shared across everyone using it this way rather than tracked per account, so it's more prone to occasional throttling under load. Price data comes from Yahoo Finance's unofficial chart API via a public proxy, since neither sends the headers browsers require for direct cross-site requests. Both automatically retry a few times before showing an error — if a search still fails, waiting a minute and trying again usually works. Google News RSS also only returns around 10 recent headlines per stock, so longer horizons may show fewer headlines than you'd expect rather than a full historical archive.
