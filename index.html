Indian Stock News Sentiment

Enter an Indian stock or company name. This pulls recent headlines from Google News and scores each one with FinVADER — a finance-tuned extension of the VADER sentiment model — then rolls the results up into a net score.

FinVADER sentiment scoring on public headlines — for demonstration only, not financial advice.

News is fetched via rss2json.com's free tier without an API key (no signup needed). Their documented free-plan limit is 10,000 requests/day per account, but this no-key usage is shared across everyone using it this way rather than tracked per account, so it's more prone to occasional throttling under load. The app automatically retries a few times before showing an error — if a search still fails, waiting a minute and trying again usually works.
